Используемые технологии: C#, Windows Forms


Требуется API ключ с сайта fixer.io


Разработано для практического задания



Настройка API-ключа



Для работы приложения требуется персональный ключ доступа к сервису \[Fixer.io](https://fixer.io/).



В целях безопасности ключ исключен из системы отслеживания версий Git (`.gitignore`).





Вы можете передать ключ в программу двумя способами:





Способ 1: Автоматическая загрузка (Рекомендуется)



1\. Создайте текстовый файл с именем `apikey.txt` в корневой папке проекта (или в каталоге с исполняемым `.exe` файлом).



2\. Вставьте ваш API-ключ в этот файл (только сам ключ, без пробелов и лишних символов) и сохраните его.



3\. При запуске приложение автоматически считает ключ и замаскирует его в интерфейсе.





Способ 2: Ручной ввод



1\. Просто запустите приложение.



2\. Если файл `apikey.txt` не найден, программа предложит ввести ключ вручную в защищенное текстовое поле на главном экране.



3\. Вставьте ключ и нажмите кнопку \*\*«Загрузить данные»\*\*.
